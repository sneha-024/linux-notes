## Week 1 Summary

During Week 1, I focused on building a strong Linux foundation through hands-on practice using Ubuntu on WSL2 and GitHub.

### Topics Covered

* Linux fundamentals and filesystem structure
* Basic terminal navigation and file management
* Users, groups, ownership, and file permissions
* Process management and system services
* Nginx installation and service administration
* Linux networking commands and troubleshooting
* Log analysis and monitoring
* grep, tail, journalctl, and Vim basics
* Git and GitHub workflow using the command line

### Hands-On Activities

* Created and managed Linux users and groups
* Configured file and directory permissions
* Installed and managed nginx services
* Investigated logs and monitored live log activity
* Practiced Linux networking troubleshooting
* Created and maintained GitHub-based Linux notes
* Used Git commands for commits, merges, pulls, and pushes

### Key Takeaway

Week 1 helped me transition from basic Linux usage to practical system administration concepts. The focus was on understanding how Linux systems operate, how services are managed, how logs are analyzed, and how common troubleshooting tasks are performed using the command line.
